Telegram Bot for Channel Access Management

Telegram-бот для управления доступом пользователей к закрытым группе и каналу с помощью одноразовых ключей.

Пользователь получает ключ от администратора, отправляет заявки на вступление в группу и канал, а затем активирует ключ через бота. После успешной проверки бот автоматически одобряет заявки. Доступ действует ограниченное время, после чего пользователь удаляется из группы и канала.

Возможности:  
 - Генерация ключей доступа администраторами.
 - Активация ключей пользователями.
 - Проверка ключа на существование и повторное использование.
 - Автоматическое одобрение заявок на вступление.
 - Управление доступом к Telegram-группе и каналу.
 - Автоматическое удаление пользователей после истечения срока действия ключа.
 - Добавление и удаление администраторов.
 - Просмотр списка администраторов.
 - Настройка ID группы и канала через команды.
 - Сохранение ключей, пользователей и настроек в файлы.
 - Обработка заявок на вступление в чат.
 - Пропуск старых Telegram-обновлений после запуска.  

Технологии:  
 - C#
 - .NET
 - Telegram Bot API
 - Telegram.Bot
 - System.Text
 - System.IO
 - JSON и текстовые файлы для хранения данных  
 
Как работает система:  
 - Администратор генерирует ключ через /getkey.
 - Бот создаёт уникальный код доступа.
 - Пользователь отправляет заявки на вступление в группу и канал.
 - Пользователь запускает /activate или /активировать.
 - Бот просит ввести полученный ключ.
 - Ключ проверяется на существование и статус активации.
 - Если ключ корректный, бот одобряет заявки пользователя.
 - Ключ помечается как использованный.
 - Данные об активации сохраняются в файл.
 - После окончания срока действия пользователь удаляется из группы и канала.
